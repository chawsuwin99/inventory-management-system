# 📦 Inventory Management System

A web-based Inventory Management System built with Laravel 12 and MySQL.

## 🚀 Project Overview

This project is a portfolio application designed to demonstrate practical web development skills using Laravel.

## ✨ Features

- Dashboard
- Product Management
- Category Management
- Supplier Management
- Stock IN and OUT Transactions
- User Authentication
- Admin and Staff Roles
- Reports and CSV Export

## 🛠️ Technologies Used

- PHP 8.2
- Laravel 12
- MySQL 8
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Laravel Breeze
- Git and GitHub

## 💻 Installation

### 1. Clone Repository

    git clone https://github.com/chawsuwin99/inventory-management-system.git

### 2. Install Dependencies

    composer install

### 3. Configure Environment

    copy .env.example .env

### 4. Generate Application Key

    php artisan key:generate

### 5. Create Database

Create a MySQL database named inventory_management.

### 6. Run Migrations

    php artisan migrate

### 7. Install Frontend Dependencies

    npm install
    npm run build

### 8. Run Application

    php artisan serve

Open http://127.0.0.1:8000 in your browser.

## 🧪 Testing

    php artisan test

## 🔐 User Roles

- Admin: Manage products, categories, suppliers, reports, and stock transactions.
- Staff: View products and manage stock transactions.
